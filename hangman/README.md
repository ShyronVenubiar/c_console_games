# Hangman (C Console Game)

A simple Hangman game written in C.  
The player must guess the hidden word letter by letter before the attempts run out.

---

## Features
- German and English Language
- Random word selection
- ASCII-based hangman drawing
- Input validation
- Replay option

---

## Play the game without compiling (Windows only)
- download and start hangman.exe in /build folder

---

## How to Compile

Using gcc:

```bash
gcc main.c -o hangman
./hangman
