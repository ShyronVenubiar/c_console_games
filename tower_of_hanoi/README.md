# Tower of Hanoi (C Console Game)
This project is a complete console implementation of the classic Tower of Hanoi puzzle, written in C.
It was one of my early learning projects and shows how I approached topics such as recursion, game states, ASCII rendering,
and input validation at the time—though without recursion, but with a manual, playable variant in which the player moves the towers themselves.

---

## Features
- Dynamic Tower height (3-9 rings)
- Color display (towers, fields)
- Simple Control via Numpad
- Detection of wether the puzzle was solved in the minimum number of moves
