# Tic-Tac-Toe (C Console Game)
A classic tic-tac-toe game for the Windows console, written entirely in C.
This project is one of my early programming efforts and shows how I approached topics such as game logic, simple AI decisions, and console interaction at the time.

---

## Features
- Control via numpad
- Opponent AI with multiple decision levels:
  - Search for winning move
  - Block
  - Place strategically next to own pieces
  - Random move as fallback
- Restart option after each game

---

## What I learned from this project
This project was an important step in my learning phase.
Among other things, I learned:
- Implementing simple AI decisions
- State management
- Error handling and input validation

Even though I would build many things in a more modular and structured way today, this project clearly shows my learning progress and my enjoyment of small game mechanics.
